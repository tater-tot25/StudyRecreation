# StudyRecreation

To Run On Local Server:

* Make sure you have PHP installed and configured in your environment variables:
https://stackoverflow.com/questions/2736528/how-to-set-the-env-variable-for-php
* Navigate to the directory that contains index.php and run: php -S localhost:8000
* In your browser go to: http://localhost:8000/index.php
* The survey should run
